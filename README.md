# Mesto — Пётр Точилкин

Финальная проектная работа: интеграция с API, валидация и вариант 1 — информация о карточке. Основа: официальный шаблон https://github.com/Yandex-Practicum/mesto-ad.

## Запуск

Нужен Node.js 22.12+ (или 20.19+). Откройте терминал в папке проекта:

```sh
npm install
npm run dev
```

В этом архиве `.env.local` уже настроен для группы `apf-cohort-203`. Для повторной настройки: скопируйте `.env.example` в `.env.local` и укажите в нём личный токен и идентификатор группы из письма Практикума. Форма выдачи: https://forms.yandex.ru/surveys/13686314.378315ce5a8c2a283de90c62581aa4b4ca4c48a4/ . Без них реальные данные сервера недоступны; сайт покажет сообщение о настройке. Тестовые карточки в приложение не включены.

```sh
npm run build
npm run preview
```

Сборка находится в `dist`. Открывать HTML двойным щелчком не нужно: используйте локальный сервер.

## Публикация

Исходники храните в приватном репозитории `mesto-ad`. Создайте отдельный публичный репозиторий для собранного сайта.

В GitHub Settings → Secrets and variables → Actions приватного репозитория добавьте:

- секреты `VITE_MESTO_TOKEN`, `VITE_MESTO_COHORT`;
- секрет `GH_PAT` с правом записи содержимого в публичный репозиторий;
- переменную `PAGES_REPOSITORY` в формате `логин/имя-публичного-репозитория`.

Запустите workflow «Publish Mesto» из вкладки Actions. Он опубликует только сборку в ветку `gh-pages` публичного репозитория. В настройках Pages этого репозитория выберите Deploy from a branch → `gh-pages` → `/ (root)`.

Для публикации из терминала задайте переменную окружения `PAGES_REPOSITORY` с HTTPS-адресом публичного репозитория и выполните `npm run deploy` (требуется настроенная авторизация Git).

Адрес опубликованного сайта добавляется сюда после настройки GitHub Pages. В текущем архиве публикация ещё не выполнена.

## Возможности

Данные профиля и карточек загружаются параллельно с сервера. Редактируются имя, описание и аватар, добавляются карточки. Удаление доступно только автору. Лайки и счётчик обновляются после ответа сервера. Кнопка «i» получает свежую информацию о карточке: название, дата, владелец, число лайков и список пользователей. Окна закрываются по крестику, фону и Escape. Формы проверяют данные, показывают ошибки и состояние отправки.

## Структура

- `src/scripts/index.js` — инициализация, обработчики, вызовы API.
- `src/scripts/components/api.js` — запросы к серверу.
- `card.js` — разметка карточек, лайки, удаление.
- `modal.js` — открытие и закрытие окон.
- `validation.js` — универсальная валидация.
- `card-info.js` — заполнение окна информации из шаблонов.
